# Muppets Theme Pack

A user package for [Agent Terrarium](https://github.com/nickvdyck/agent-terrarium) featuring characters from The Muppet Show.

## Contents

### Agents (6)
| Avatar | Movement | Personality |
|--------|----------|-------------|
| 🐸 **Kermit** | Wander | High interaction, moderate speed — the natural host |
| 🐷 **Miss Piggy** | Wander (waddle) | Slow but can sprint, low ball interest — glamorous diva |
| 🎺 **Gonzo** | Bounce | Fast, chases everything — the great daredevil |
| 🐻 **Fozzie Bear** | Wander (waddle) | Desperate for an audience, moderate speed |
| 🥁 **Animal** | Bounce | Very fast, wild, antisocial — pure chaos energy |
| 🐶 **Rowlf** | Wander | Slow, laid-back, chill — the mellow pianist |

### Theme
🎭 **Muppet Theater** — Dark red velvet curtains, wood stage floor, spotlights, gold sparkle particles, vaudeville music. Dynamic sky disabled (indoor theater).

### Gear (5)
- 🎩 Fozzie's Hat — porkpie hat (hat slot)
- 🪕 Kermit's Banjo — (body slot)
- 📿 Piggy's Pearls — pearl necklace (neck slot)
- ⛓️ Animal's Chain — metal chain (neck slot)
- 🎺 Gonzo's Trumpet — brass trumpet (body slot)

## Installation

Copy the `muppets/` folder to your Agent Terrarium user packages directory:

**Windows:**
```
%USERPROFILE%\agent-terrarium\packages\muppets\
```

**macOS / Linux:**
```
~/agent-terrarium/packages/muppets/
```

The app will detect the new package automatically (hot-reload). No restart needed.
